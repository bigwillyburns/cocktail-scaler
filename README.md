# Cocktail Scaler

Build cocktail recipes in ml, oz or dashes, see their ABV, save them to a
Cocktail List and scale them to any batch size, with a shopping list of the
bottles to buy.

It's a home-screen web app for iPhone, in [`web/`](web/). See
[web/README.md](web/README.md) for how to run, host and install it.

Live app: https://bigwillyburns.github.io/cocktail-scaler/
