# Cocktail Scaler

Build cocktail recipes in ml, oz or dashes, see their ABV, save them to a
Cocktail List and scale them to any batch size.

- [`web/`](web/): the iPhone home-screen web app (the one that's hosted).
  See [web/README.md](web/README.md).
- [`CocktailScaler/`](CocktailScaler/): a native SwiftUI version, which
  needs a Mac with Xcode to build.

Live app: https://bigwillyburns.github.io/cocktail-scaler/
